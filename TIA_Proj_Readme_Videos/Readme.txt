BGM_virt_Bedfeld.zip ist ein fertiges TIA-V17 Projekt für das virtuelle Dr. Kahlert Modell "Biegevorrichtung". Entpacken und in TIA-V17 starten.
Virtuelles_Bedienfeld.zip ist ein Programm, dass ein Bedienfeld im Browser aufmacht mit dem man dann die "Biegevorrichtung" bedienen kann. Es benötigt eine laufende PLCSim-Advanced Instanz. Entpacken und über bedienpanel.exe starten.
